# Stove 럭키 캡슐 자동 뽑기 (Chrome Extension)

스토브 리워드 이벤트 페이지(`https://reward.onstove.com/ko/event`)에서 100 또는 1,000 플레이크 뽑기 및 결과 대화창의 **'한번 더'** 클릭을 이벤트 기반으로 자동화하는 크롬 확장 프로그램입니다.

---

## 1. 설치 방법 (개발자 모드 로드)

1. 압축 파일을 원하는 경로에 압축 해제합니다.
   - **주의**: 설치 후 압축 해제한 `app` 폴더를 삭제하거나 다른 위치로 이동하면 확장 프로그램이 동작하지 않습니다.
2. 크롬 브라우저 주소창에 `chrome://extensions` 를 입력하여 이동합니다.
3. 우측 상단의 **[개발자 모드]** 스위치를 켭니다.
4. 좌측 상단의 **[압축해제된 확장 프로그램을 로드합니다.]** 버튼을 클릭하고, 압축을 푼 경로 내의 **`app`** 폴더를 선택합니다.
5. 브라우저 우측 상단 퍼즐 아이콘(확장 프로그램)을 클릭하고 핀(고정) 아이콘을 눌러 툴바에 고정합니다.

---

## 2. 사용 방법

1. 스토브 리워드 이벤트 페이지(`https://reward.onstove.com/ko/event`)에 접속하여 로그인합니다.
   - 확장 프로그램 설치 전부터 탭이 열려 있었다면 `F5` 키를 눌러 페이지를 한 번 새로고침합니다.
2. 툴바에 고정된 **Stove 럭키 캡슐 자동 뽑기** 아이콘을 클릭합니다.
3. 팝업 창 상단에 표시된 오늘 뽑기 현황(`X / 30회`)과 자동 계산된 최대 실행 횟수를 확인합니다.
4. 뽑기 금액(`100 플레이크` 또는 `1,000 플레이크`)과 `'한번 더'` 실행 횟수를 선택한 뒤 **[자동 뽑기 시작]** 버튼을 클릭합니다.
5. 진행 중 멈추고 싶다면 팝업의 **[중단]** 버튼을 누르거나, 웹페이지 대화창의 **[닫기]** 버튼 또는 `Esc` 키를 누르면 즉시 안전하게 중단됩니다.

---

## 3. 자동 종료 조건

- 당일 최대 한도(30회)에 도달하여 `오늘 30회 뽑기 완료!` 창이 나타난 경우
- 보유 플레이크가 소진되어 `보유한 플레이크가 부족합니다` 창이 나타난 경우
- 일시적인 서버 통신 오류가 발생한 경우
- 사용자가 대화창을 닫거나 중단 버튼을 누른 경우
